## Reconnaissance Aktif — Teknik Lengkap

### Nmap Advanced Techniques
```bash
# Full TCP SYN scan semua port dengan service/version detection
nmap -sS -sV -sC -p- --min-rate 5000 -oA full_scan <target>

# UDP scan (lebih lambat, tapi penting)
nmap -sU --top-ports 1000 -oA udp_scan <target>

# OS detection
nmap -O --osscan-guess <target>

# Firewall bypass techniques
nmap -f <target>                    # Fragment packets
nmap -D RND:10 <target>             # Decoy scan
nmap --source-port 53 <target>      # Spoof source port (DNS)
nmap -sA <target>                   # ACK scan (firewall rule mapping)

# Script categories
nmap --script=vuln <target>         # Vulnerability check
nmap --script=auth <target>         # Authentication bypass tests
nmap --script=exploit <target>      # Exploitation scripts
nmap --script=smb-vuln* <target>    # SMB vulnerabilities (EternalBlue, etc)
```

## Post-Exploitation

### Linux Privilege Escalation Checklist
```bash
# System info
uname -a; id; whoami; hostname; cat /etc/os-release

# SUID/SGID
find / -perm -4000 -o -perm -2000 2>/dev/null | xargs ls -la

# Sudo rights
sudo -l

# Writable directories
find / -writable -type d 2>/dev/null

# Cron jobs
cat /etc/crontab; ls -la /etc/cron*; crontab -l

# Running processes
ps aux; netstat -tlnp

# Sensitive files
cat /etc/passwd; cat /etc/shadow (jika readable)
find / -name "*.conf" -o -name "*.config" 2>/dev/null | xargs grep -l "password" 2>/dev/null
find / -name "id_rsa" -o -name "*.pem" -o -name "*.key" 2>/dev/null

# PATH hijacking
echo $PATH; find . -type f -perm -o+w 2>/dev/null

# Docker escape
find / -name docker.sock 2>/dev/null
```

### Windows Privilege Escalation
```powershell
# System info
systeminfo; whoami /all; net user; net localgroup administrators

# Unquoted service paths (classic vuln)
wmic service get name,pathname | findstr /i /v "C:\Windows\\" | findstr /i /v """

# AlwaysInstallElevated
reg query HKCU\SOFTWARE\Policies\Microsoft\Windows\Installer /v AlwaysInstallElevated
reg query HKLM\SOFTWARE\Policies\Microsoft\Windows\Installer /v AlwaysInstallElevated

# Credentials in registry
reg query HKLM /f password /t REG_SZ /s

# Weak service permissions
sc qc <service_name>
accesschk.exe -uwcqv "Everyone" *

# PowerShell history
(Get-PSReadlineOption).HistorySavePath | Get-Content
```

## Analisis Malware — Teknik Dasar

### Static Analysis
```bash
# File identification
file malware.bin
strings malware.bin | grep -E "(http|\.exe|cmd|powershell)"
xxd malware.bin | head -20   # Hex dump

# PE analysis (Windows executable)
pecheck malware.exe
pescan malware.exe
readelf -h malware.elf       # Linux ELF

# Import table (Windows)
dumpbin /imports malware.exe
# Dangerous imports: CreateRemoteThread, WriteProcessMemory, VirtualAllocEx → code injection

# Hash untuk threat intel
md5sum malware.bin
sha256sum malware.bin
# Cek di: VirusTotal, MalwareBazaar, AnyRun
```

### Dynamic Analysis (Sandbox)
```
Tools: Cuckoo Sandbox (self-hosted), AnyRun, VirusTotal sandbox, Joe Sandbox

Yang diamati:
- Network connections (C2 server, exfiltration)
- File system changes (persistence, payload drop)
- Registry modifications
- Process creation (child processes, injection)
- API calls (behavioral analysis)

Tools lokal:
- Process Monitor (Procmon) — file/registry/network activity
- Wireshark — network traffic
- Process Hacker — memory dan proses
```

### Indicators of Compromise (IOC)
```
Kategori IOC:
- Hash: MD5, SHA1, SHA256 dari file malware
- IP: Alamat C2 server
- Domain: Domain C2 atau dropper
- URL: URL download payload
- Registry key: Persistence mechanism
- Mutex: Identifier unik malware (mencegah double infection)
- File path: Lokasi malware menaruh file

Format sharing IOC: STIX/TAXII, MISP, OpenIOC
```

### Log Analysis untuk SOC
```python
# Parse Apache access log
import re
from collections import Counter, defaultdict
from datetime import datetime

LOG_PATTERN = r'(\d+\.\d+\.\d+\.\d+) .* \[(.*?)\] "(.*?)" (\d+) (\d+|-)'

def analyze_logs(log_file):
    ip_requests = Counter()
    status_errors = defaultdict(list)
    suspicious = []
    
    with open(log_file) as f:
        for line in f:
            m = re.match(LOG_PATTERN, line)
            if not m:
                continue
            ip, timestamp, request, status, size = m.groups()
            ip_requests[ip] += 1
            
            # Deteksi SQL injection attempt
            if any(p in request.lower() for p in ["'", "union select", "1=1", "or 1"]):
                suspicious.append({"ip": ip, "request": request, "type": "SQLi"})
            
            # Deteksi path traversal
            if "../" in request or "..%2F" in request.lower():
                suspicious.append({"ip": ip, "request": request, "type": "PathTraversal"})
            
            # 4xx/5xx errors
            if status.startswith(('4', '5')):
                status_errors[ip].append(status)
    
    return {
        "top_ips": ip_requests.most_common(10),
        "suspicious": suspicious,
        "brute_force_candidates": [ip for ip, errs in status_errors.items() 
                                   if errs.count('401') > 10 or errs.count('403') > 20]
    }
```
